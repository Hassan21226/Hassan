لذة الأجداد — نسخة أولية قابلة للتعديل

الملفات:
- index.html: صفحة المنيو العامة
- admin.html: صفحة إدارة تجريبية لتعديل أسماء الأطباق والأحجام والأسعار
- style.css: التصميم والألوان والتجاوب مع الجوال
- app.js: عرض الأطباق والبحث وتبديل السعر عند الضغط على الحجم

التشغيل:
1. فك ضغط الملف.
2. افتح index.html في المتصفح.
3. افتح admin.html لتعديل بيانات المنتجات.
4. اضغط «حفظ التعديلات» ثم افتح صفحة المنيو.

ملاحظات مهمة:
- هذه نسخة أولية مستقلة وليست متصلة بموقع sacredkoala16.chatgpt.site الحالي.
- الحفظ في هذه النسخة يتم محليًا داخل المتصفح فقط؛ لا توجد قاعدة بيانات أو تسجيل دخول حقيقي.
- السعر المعروف من صورك: وسط 120 ريال، كبير 150 ريال. لم يتم اختراع سعر للصغير.
- أضف صور المنتجات الحقيقية من لوحة الإدارة/الكود عند تجهيز النسخة المنشورة.
- لنشر الموقع على رابط عام تحتاج رفع هذه الملفات إلى خدمة استضافة أو إلى محرّر الموقع الأصلي. هذا المشروع لا يغيّر الرابط الحالي تلقائيًا.
