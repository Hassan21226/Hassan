# إعداد نشر لذة الأجداد

تمت إضافة مهمة GitHub Actions باسم Publish menu to Cloudflare، لإنشاء قاعدة البيانات والتخزين ونقل المنيو ثم نشر الموقع كاملًا.

اتبع [دليل ربط الحساب والتفعيل](deployment/SETUP-AR.md).

نجح بناء التطبيق محليًا بإعداد Cloudflare المستقل، واختبار محاكاة إنشاء القاعدة والتخزين وترحيل المنيو وإعادة التشغيل دون استبدال بيانات الوجهة. لم يُنفّذ النشر الفعلي لعدم توفر بيانات حساب Cloudflare.
